# 开发路线

> 架构约定：一级业务页面仅三个 —— 统计 / 记账 / 日价。
> 记账页同时为 App 默认首页（打开 App 直接进入记账主界面）；设置经右上角菜单进入，不属于一级 Tab。
> 原“首页 / 记账”为旧版对需求的错误拆分，已合并为单一“记账主界面”，不存在独立首页 Dashboard。

Phase 0
基础工程。

Phase 1
Design System + Core Data Layer。

Phase 2
v1 → v2 数据迁移。

Phase 3
记账主界面（App 默认首页）。

内容：
- 默认首页
- 顶部统计/记账/日价切换骨架
- 绿色月份汇总卡
- 月份卡左右滑动
- 账单时间线
- 切换月份后时间线自动滚到对应月份最顶部
- 账单滚到底部的到达动画
- 右下角 +
- 快速记账半屏 Sheet
- 数字键盘 / 文字键盘切换
- 最近使用分类
- 展开全部分类
- 自定义分类
- 长按分类删除/管理
- Android 返回键交互

Phase 4
统计。

内容：
- 顶部月份控制
- 环形百分比图
- 柱状趋势图
- 基础消费概览
- 为以后统计扩展保留模块接口

Phase 5
日价。

内容：
- Bill.dailyValue 关联
- 每日总日价
- 物品展览
- 已使用天数
- 当前每日成本
- 情绪价值展示

Phase 6
Theme / Wallpaper。

Phase 7
周期记账 / Widget 等扩展。
